# ONE CLUB — Coming Soon

A lightweight, responsive HTML/CSS landing page for `oneclub.net.in`.

## Structure

```text
oneclub-coming-soon/
├── index.html
├── CNAME
├── css/
│   └── style.css
└── assets/
    └── logo.png
```

## Replacing the temporary logo

Replace:

`assets/logo.png`

with the final ONE CLUB logo.

Keep the filename `logo.png` and the HTML/CSS does not need to be changed.

If your final logo has a different filename or format, change the `src` in `index.html` accordingly.

## No background image

The page design is built with HTML + CSS. The background is made from CSS gradients and subtle geometric elements. There is no full-page background image.

## GitHub Pages

Upload the files to the repository root, preserving the folder structure.

Then:
1. Repository → Settings → Pages
2. Source → Deploy from a branch
3. Branch → `main`
4. Folder → `/ (root)`
5. Save

The included `CNAME` file is already set to:

`oneclub.net.in`

Configure the GitHub Pages DNS records at GoDaddy without deleting the Google Workspace MX records.
